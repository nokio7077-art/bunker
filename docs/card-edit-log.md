## Уточнение особых условий, фобии и бессонница

Прежние 16 сюжетных особых условий заменены на 16 карт действий. Применение проверяется сервером, выполняется целиком, расходуется один раз и сохраняется вместе с комнатой. Использовать можно в свой ход, до изгнания; обычное раскрытие карточки остаётся обязательным, если есть что раскрывать. Скрытые значения при сбросе не попадают в журнал. Перетасовка затрагивает только открытые несброшенные карточки. При выборе замены показывается вся подходящая колода, чтобы не выдавать чужую руку через недоступные варианты. Повторы после такого выбора допустимы.

Из `data/health.json` удалён ID 11, «Смертельная семейная бессонница». Это единственная карточка здоровья со словоформой от «смертел». Обычная «Хроническая бессонница» остаётся. В колоде здоровья теперь 159 карточек.

Источник фобий — новый присланный текст из 100 пронумерованных позиций (группы по десять). В `data/phobia.json` сохранены исходные сквозные номера в порядке текста; итог — 90 карт. Сам текст содержит фразы из предыдущего диалога с другой моделью, которые не являются правилами игры и в данные не включены.

Для спорных названий, которым текст приписывает несоответствующие значения, используются понятные игровые формулировки: страх поломок, жёстких расписаний, распределения ресурсов, физического истощения, открытого неба, оценки внешности. Убраны обороты «смертельный страх». Страхи не объявляются автоматической неспособностью жить в бункере, запретом действий или обязательным выбором при голосовании.


## Случайная замена, исходные характеры и экран катастрофы

По следующему уточнению пользователя выбор конкретной новой карточки убран. Семь особых условий замены теперь используют `redraw`: сервер выбирает случайный элемент подходящей колоды, исключая текущее значение. Проверки биологии и катастрофы сохраняются. Передать желаемое значение через API нельзя; такой запрос отклоняется без расходования условия. Карточка и признак использования сохраняются вместе, поэтому перезагрузка не позволяет перебросить результат. Открытость слота сохраняется.

В `data/personality.json` восстановлены все 25 исходных названий из ранее присланного текстового списка, включая «Расист» и «Гомофоб». Описания кратко характеризуют предубеждения и поведение вымышленного персонажа; они не предписывают обязательное голосование или оскорбления других участников. Ранее предложенные 25 альтернативных черт заменены исходными; 16 спокойных черт сохранены. Ранее разданные персонажи не меняются посреди партии.

После старта партии катастрофа показывается каждому участнику на весь экран перед досье. Кнопка «О ужас! Дальше» переводит в комнату. Просмотр сохраняется отдельно для кода комнаты и ID игрока в этом браузере; следующая партия получает собственный экран. Обновления комнаты не прерывают чтение. Поддержан старый формат катастроф без дополнительных числовых полей.

Новый архив `bunker-cards.zip` не был прочитан или импортирован: инструмент передачи файлов отклонил его из-за лимита 32 МиБ. Эти правки используют ранее доступные текстовые материалы и текущие колоды репозитория.


## Подключение изображений из репозитория

Использованы 23 PNG, загруженные пользователем коммитом `03418d6` в корень репозитория. Файлы перенесены в `public/images/cards/disasters/` без перекодирования и изменения содержимого; SHA-256 до и после переноса совпадает. Номера файлов связаны с ID катастроф в `public/card-images.js`.

Стартовый экран показывает готовое изображение карточки с кнопкой «О ужас! Дальше», переключением на читаемый текст и автоматическим текстовым вариантом при ошибке загрузки. Из комнаты можно открыть изображение повторно. Готовые изображения содержат собственные надписи и цифры: если сценарий в JSON меняется, изображение нужно обновить отдельно. Загруженные файлы относятся только к катастрофам, поэтому изображения бункеров не добавлялись.


## Обновление главной и мобильной версии

Архив `bunker-main (3).zip` сравнен с рабочим проектом. Все прежние игровые изменения сохранены: 500 профессий с описаниями, отдельные фобии, исходные характеры, случайная замена карт, 23 изображения катастроф в папке, полноэкранный старт с кнопкой «О ужас! Дальше» и тестовая игра с ботами. Архив не заменял более новые рабочие файлы целиком.

Главная переработана по присланному макету с функциональными формами и фоном, подготовленным по референсу. Из архива учтён выбор Rubik Mono One: кириллический шрифт включён локально с OFL-лицензией вместо внешних ссылок Google Fonts, которые ограничивались CSP приложения. Рамки, кнопки и статистика выполнены в HTML/CSS; декоративные пиктограммы не подменяют элементы управления.

Адаптивная вёрстка учитывает ширины от 320 px: колонки имеют ограниченную минимальную ширину, длинные названия переносятся, мелкие карточки заменены одной колонкой на узких телефонах, поля ввода увеличены до 16 px, кнопки и диалоги адаптированы под касание. При голосовании участники идут перед досье. Изменения подготовлены в рабочем черновике, без отправки в GitHub и публикации Render.

## Шапка, загрузка и игровые действия

- Общая обложка комнаты и компактная навигация вместо повторяющихся номеров и растянутого заголовка.
- 23 карточки WebP сохраняют исходное разрешение и уменьшают общий объём на 42%; пейзаж — на 84%. Исходные PNG сохранены. Имена производных содержат хеш, сервер отдаёт их с длительным кэшированием.
- Видео сохраняет mute/playsinline/loop; добавлено повторное воспроизведение при событии ended. Проверены два естественных цикла в браузере.
- Публичные результаты особых условий с открытыми значениями до/после, скрытые значения в события не попадают.
- Колода характеров расширена до 100 описанных черт; сохранены все 41 старые карточки.
- Вероятности генератора ориентаций 93/3/3/1%, всего 7% негетеросексуальных персонажей. Это заданные игровые веса.
- Голос отправляется по галочке, боты голосуют автоматически после всех людей, включая изгнанных. Старый серверный вызов bot_votes оставлен для совместимости.
- Изменения объединены с новой пиксельной темой из main: оформление игровых блоков сохранено, устаревшая шапка и узкие мобильные карточки заменены проверенным вариантом.
